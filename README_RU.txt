FY_POOL_DAY — TELEGRAM MINI APP + MULTIPLAYER
============================================
Версия 1.2.1 — два режима: локальный хост игрока и облачный сервер.

ЧТО РЕАЛИЗОВАНО В ЭТОЙ СБОРКЕ
------------------------------
- Игра адаптирована для запуска внутри Telegram Mini App (Telegram WebApp SDK).
- Имя игрока автоматически берётся из профиля Telegram, если приложение открыто в Telegram.
- Комната может передаваться через deep-link startapp.
- Есть выбор режима сервера: «Свой компьютер (хост)» или «Облачный сервер».
- Есть кнопка приглашения в комнату через Telegram.
- Добавлен минимальный Telegram-бот: /start отправляет кнопку открытия Mini App.
- Добавлен webhook endpoint /telegram/webhook и скрипт установки webhook.
- Добавлена конфигурация Fly.io (fly.toml + Dockerfile) для облачного WebSocket-сервера.

СТРУКТУРА
---------
index.html                 Игра / Mini App
telegram-config.js         Публичные настройки URL облака и username бота
server/server.js           WebSocket-сервер + Telegram webhook
server/set-webhook.js      Установка webhook бота в Telegram
server/.env.example        Список переменных окружения
fly.toml / Dockerfile       Шаблон облачного развёртывания на Fly.io

ЧАСТЬ 1. СОЗДАТЬ TELEGRAM-БОТА
------------------------------
1. Откройте @BotFather в Telegram.
2. Выполните /newbot и создайте бота. Сохраните BOT_TOKEN в секрете.
3. После публикации Mini App задайте его HTTPS-адрес через настройки Mini Apps в BotFather
   (или используйте кнопку Web App, которую отправляет бот по команде /start).
4. Запомните username бота без @.

ЧАСТЬ 2. ОПУБЛИКОВАТЬ MINI APP (HTTPS ОБЯЗАТЕЛЕН)
-------------------------------------------------
Telegram Mini App нельзя открыть с file:// или обычного http:// адреса.
Загрузите index.html и telegram-config.js на HTTPS-хостинг статических файлов:
Firebase Hosting, GitHub Pages с HTTPS, Netlify или аналогичный.
Оба файла должны лежать рядом в одной папке.

Откройте telegram-config.js и заполните:
  window.GAME_CONFIG = {
    cloudWsUrl: "wss://ИМЯ-ВАШЕГО-ПРИЛОЖЕНИЯ.fly.dev",
    botUsername: "username_вашего_бота"
  };

После этого опубликуйте файлы повторно. В BotFather укажите тот же HTTPS URL Mini App.

ЧАСТЬ 3. ОБЛАЧНЫЙ СЕРВЕР НА FLY.IO (ПОСТОЯННЫЙ АДРЕС)
--------------------------------------------
1. Создайте репозиторий GitHub и загрузите содержимое этой папки.
2. Установите Fly CLI: https://fly.io/docs/flyctl/install/
3. В папке проекта выполните:
     fly auth login
     fly launch --no-deploy
   Fly определит fly.toml (приложение fy-pool-day, регион waw).
   Если имя занято, Fly предложит другое — используйте его во всех шагах ниже.
4. Задайте секреты (вместо fy-pool-day подставьте имя вашего приложения):
     fly secrets set BOT_TOKEN="ТОКЕН_ОТ_BOTFATHER"
     fly secrets set WEBAPP_URL="https://ИМЯ-СТАТИКИ.github.io/РЕПО/"
     fly secrets set WEBHOOK_SECRET="случайная_строка_из_букв_цифр"
     fly secrets set PUBLIC_SERVER_URL="https://fy-pool-day.fly.dev"
5. Задеплойте:
     fly deploy
6. После деплоя сервер сам установит Telegram-webhook (нужны все 4 секрета).
   Проверка: https://fy-pool-day.fly.dev/health должен вернуть JSON с ok:true.
   WebSocket URL для telegram-config.js:
     wss://fy-pool-day.fly.dev
7. В telegram-config.js пропишите:
     cloudWsUrl: "wss://fy-pool-day.fly.dev"
     botUsername: "username_вашего_бота"
   и опубликуйте index.html + telegram-config.js на HTTPS-хостинге (см. ЧАСТЬ 2).

Мини-приложение (index.html и telegram-config.js) размещается отдельно на
GitHub Pages: Settings → Pages → Deploy from branch → main → / (root).

Для игры игрокам достаточно выбрать «Облачный сервер» и подключиться.
Приложение Fly засыпает при простое и просыпается на первый запрос; первый
запуск после простоя может быть медленным. Для постоянной доступности без
задержек увеличьте min_machines_running в fly.toml (платно по секундам).

ЧАСТЬ 4. ЛОКАЛЬНЫЙ ХОСТ — ИГРА ЧЕРЕЗ ИНТЕРНЕТ
---------------------------------------------
1. На компьютере хоста установите Node.js 18+.
2. Откройте папку server и запустите INSTALL.bat.
3. Запустите START_INTERNET.bat.
4. Сервер создаст временный публичный WSS-адрес через localtunnel и покажет его в консоли.
5. Откройте Mini App в Telegram на устройстве хоста, выберите режим
   «Свой компьютер (хост)» и вставьте выданный wss:// адрес.
6. Создайте/укажите код комнаты и нажмите «Подключиться».
7. Передайте друзьям тот же WSS-адрес и код комнаты. Они открывают Mini App,
   выбирают локальный режим, вставляют адрес и подключаются.
8. Окно сервера на компьютере хоста должно оставаться открытым до конца матча.

Локальный режим требует, чтобы компьютер хоста был включён. Если хост отключится,
матч прекратится. Интернет-туннель создаёт временный адрес; после перезапуска он
может измениться. Для Telegram Mini App нужен именно публичный wss:// адрес, а не
ws://localhost, потому что Mini App загружается по HTTPS.

ПРИГЛАШЕНИЯ
-----------
Кнопка «Пригласить в комнату» формирует Telegram deep-link вида startapp=<код комнаты>.
Для корректной работы задайте botUsername в telegram-config.js и настройте Mini App
у BotFather. Если кнопка не может открыть Telegram, скопируйте/отправьте ссылку вручную.

ВАЖНЫЕ ОГРАНИЧЕНИЯ ТЕКУЩЕГО ПРОТОТИПА
------------------------------------
- Это рабочая интеграционная заготовка Mini App и двух режимов размещения, но её
  необходимо развернуть с собственным BOT_TOKEN, HTTPS URL и адресом WSS-сервера.
- WebSocket-прототип пока не проверяет Telegram initData криптографически на сервере.
  Имя из Telegram используется для интерфейса, но не является подтверждённой учётной записью.
- Нет полноценной защиты от читов, серверной авторитетной симуляции физики и рейтингов.
- Игровые комнаты хранятся в памяти процесса; при перезапуске сервера они исчезают.
- Облачный сервер и локальный сервер используют один и тот же сетевой протокол.
- Нельзя считать сборку готовой к публичной эксплуатации без реального теста на двух
  устройствах и проверки Telegram-бота после добавления секретов и доменов.

ПРОВЕРКА
--------
Облачный сервер: https://АДРЕС/health должен вернуть JSON с ok:true.
Telegram: отправьте боту /start и откройте Mini App из появившейся кнопки.


ПРИМЕЧАНИЕ К ЧИСТОЙ СБОРКЕ
---------------------------
В комплект входят только файлы, необходимые для игры, локального relay и облачного
развёртывания. Временные исполняемые файлы туннелей, журналы и локальные настройки
предыдущих запусков в архив не включены.
